# Deshal 13 (দেশাল ১৩) — Zero-Config GitHub + Vercel Edition

No database, no Supabase, and no environment variables required.

## Deploy in 2 Steps:
1. Create a new repository on GitHub and upload `index.html` and `vercel.json`.
2. Go to Vercel -> **Add New -> Project** -> Import your GitHub repository -> Click **Deploy**.
